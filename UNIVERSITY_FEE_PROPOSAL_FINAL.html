3. Custom Report and Documentation Note

Software-generated reports available inside the application are treated as part of the software workflow and normal use. Therefore, a separate high report charge is not being proposed for routine use of the reporting features already present in the application.

However, if the university separately requests a custom written technical note, inspection summary, compliance note, recommendation document, or additional special report outside the software-generated reports, the same may be charged separately.

Suggested custom written report charge, only if separately requested:
Rs 10,000 to Rs 15,000 per report

In addition, if any software-related professional service is required by the university beyond the present scope, I shall also be available to provide support on mutually agreed commercial terms.

  • New dashboard sections or analytics pages
  • New reports or new report formats
  • Formula or calculation changes
  • New user roles, permissions, or workflow changes
  • Database changes
  • Sensor, API, device, or system integration
  • AI prediction enhancement or advanced logic updates
  • Any new software module requested later
Suggested reference structure:
Minor changes: Rs 5,000 to Rs 15,000
Medium feature additions: Rs 15,000 to Rs 40,000
Major module / advanced integration / substantial enhancement: separate project-based quotation
