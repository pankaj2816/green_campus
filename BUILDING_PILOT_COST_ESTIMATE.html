MAHE Green Campus Dashboard (MGCD)

Single Building Cost Estimate Report

This report is only for cost estimation. It focuses on expected initial investment and recurring annual cost for implementing the current MGCD platform on one campus building as a practical pilot.

Recommended CAPEX Rs 1.08 lakh to Rs 1.35 lakh
Best realistic range for one useful pilot building.
Recommended OPEX Rs 56,000 to Rs 1.08 lakh / year
Includes hosting, support, maintenance, and small replacements.
Planning Figure Rs 1.2 lakh initial + Rs 70,000 yearly
Use this number for early budgeting and approval discussion.
Scope Used One pilot building
Main incomer, 3 internal points, one edge collector, basic water visibility, optional solar tie-in.

1. Cost Assumptions

This estimate assumes one academic or admin building with moderate electrical complexity. It does not assume full campus-wide metering. It also assumes that the current MGCD software is used as the dashboard layer and only the building-level live enablement is added.

  • 1 main building energy meter point plus 3 internal monitoring points
  • 1 edge collector device for data reading and forwarding
  • basic network, UPS, wiring accessories, and enclosure
  • starter water visibility only, not full building water SCADA
  • solar source already available from inverter or one extra feeder meter if needed
  • software configuration, device mapping, and dashboard enablement included as a project cost
